## 不变的边界

其他三方不能增加积分；业务幂等键不可复用不同参数；积分余额不可为负；三方不能自称官方；应用角色不能影响平台角色；没有明确授权即拒绝；生产秘密只保存在服务器秘密目录，不进入本文档和仓库。
